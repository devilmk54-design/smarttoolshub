JSON Formatter & Validator

Format, beautify, minify and validate JSON with clear error messages.

How to use the JSON Formatter & Validator

  1. Paste your JSON into the first box.
  2. Press Format to indent it, or Minify to compress it.
  3. Read the validity message and copy the output.

About this tool

JSON is the standard data format for APIs and configuration files, but raw JSON often arrives as one unreadable line. This tool re-indents it with two spaces so you can read and debug it, or minifies it to save bytes.

If your JSON is invalid, the browser’s parser reports what went wrong, which usually points to a missing comma, an unquoted key or a trailing comma. Processing is local, but you should still avoid pasting secrets into any website.

Frequently asked questions

What makes JSON invalid?

Common causes are single quotes, trailing commas, unquoted keys and comments.

Does it sort keys?

No. The original key order is kept.

Is there a size limit?

Only your browser’s memory. Very large inputs may feel slow.
