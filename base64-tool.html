Base64 Encoder & Decoder

Encode text to Base64 or decode Base64 back to text, with full Unicode support.

How to use the Base64 Encoder & Decoder

  1. Paste your text or Base64 string into the input box.
  2. Press Encode to convert text to Base64, or Decode to convert it back.
  3. Copy the result.

About this tool

Base64 turns text or binary data into plain ASCII characters so it can travel safely through email, URLs, JSON and HTML. Developers meet it in data URIs, API tokens and basic authentication headers.

This tool encodes through UTF-8, so emoji and non-English letters work correctly, which simpler tools often get wrong. It also accepts URL-safe Base64 (using - and _) when decoding. Remember that Base64 is an encoding, not encryption: anyone can decode it.

Frequently asked questions

Is Base64 secure?

No. It hides nothing, so never use it to protect passwords.

Why does decoding fail?

The input contains characters outside the Base64 alphabet, or it was cut off.

Can it encode files?

This version handles text only.
